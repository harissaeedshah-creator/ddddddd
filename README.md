# Neon Maze Invaders

A neon-soaked, 70s arcade inspired web game that blends Pac-Man-style pellet runs with Space Invaders pressure.

## How to play

1. Start a local server in this directory:

```bash
python -m http.server 8000
```

2. Open `http://localhost:8000` in your browser.

## Controls

- **Move:** WASD or Arrow Keys
- **Fire:** Space
- **Dash:** Shift (when charged)

Collect pellets to charge up your power mode, blast invaders, and survive the neon maze.
